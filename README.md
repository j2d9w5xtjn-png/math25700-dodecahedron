# Dodecahedron Rotations

Interactive rotations of the regular dodecahedron: the 60 rotations act on its five inscribed cubes as the even permutations, so the rotation group is isomorphic to A5 (Math 25700, Lecture 3).

Live page: https://j2d9w5xtjn-png.github.io/math25700-dodecahedron/

`index.html` is a built copy; the source and tests are kept elsewhere.
